# iOS Boot Clone (Bare-metal x86 OS for QEMU)

Клон экрана загрузки iOS / Apple, работающий как самостоятельная загружаемая ОС без сторонних загрузчиков.

## Особенности
- **16-битный MBR загрузчик** ([`src/boot.asm`](file:///home/suslan/iboot_clone/src/boot.asm)): инициализирует VESA VBE 1024x768x32bpp с Linear Framebuffer, A20, переходит в 32-битный защищённый режим.
- **Ядро C/ASM** ([`src/kernel.c`](file:///home/suslan/iboot_clone/src/kernel.c)):
  - Стартовый экран **BROM** (симуляция boot ROM Apple: `brom -> llb -> iboot -> xnu`) с мигающим приглашением — загрузка с яблоком продолжается только после нажатия **Enter**.
  - Отрисовка сглаженного белого логотипа Apple по центру экрана (RLE-сжатие альфа-маски из `apple.png`).
  - Тонкий прогрессбар с закруглениями снизу логотипа (трек `#2c2c2e`, заполнение `#ffffff`).
  - Задержка прогрессбара реальная, не имитируемая: заполнение растёт по мере фактической работы ядра — детект RAM, обнуление кучи, CRC32 образа ядра, ATA PIO-верификация 128 секторов с диска, распаковка RLE-ассетов, паттерн-тест памяти, self-test i8042.
  - Таймер на базе PIT channel 2 (микросекундная точность без прерываний).
  - Плавный fade-out в чёрный экран в конце загрузки с возможностью перезапуска по нажатию клавиши.
- **Рабочий стол** (`os_main`) после завершения загрузки:
  - Обои на весь экран — `wall1` / `wall2` (RLE, 16-bit), переключение через Wallpaper Set.
  - Иконки перетаскиваются мышью (ЛКМ зажать на иконке), позиция прилипает к сетке `ICON_GRID`; стартовые позиции в `apps[]` заданы ровно по этой сетке (кратны `ICON_GRID`).
  - Иконки приложений скругляются **программно** (радиус `WALL_ICON_R`, 2px антиалиасинг краёв) — квадратный bitmap превращается в iOS-подобную скруглённую иконку; так устроены все будущие иконки.
  - **Wallpaper Set** — первое приложение (иконка из `wallpaper_icon.bmp`): открывается **двойным нажатием** (так же будут открываться все будущие приложения), показывает превью `wall1`/`wall2`, двойное нажатие по превью устанавливает обои, закрыть — `X` или `Esc`.
  - **Settings** (иконка из `settings_icon.bmp`): открывается **двойным нажатием**, внутри две вкладки — **Time** (выбор часового пояса, часы в панели задач сдвигаются на выбранный offset) и **Taskbar** (панель вниз или снова наверх). Кнопки внутри окна работают по **одинарному** нажатию, закрыть — кнопка `X` (текстура `close.bmp`, скругление программное) или `Esc`.
  - **Панель задач** (22px, время/дата из CMOS RTC справа) по умолчанию сверху; после переноса вниз иконки при перетаскивании её не перекрывают.
  - Закрытие любого окна — через одну базу `close_app()`: рамка схлопывается к центру за 12 кадров (~240 мс). Новое приложение достаточно вызывать из `on_double_click`/`close_app`, анимация и `X` уже общие.

## Управление (горячие клавиши)
- **`Enter`** (только на экране BROM): продолжить загрузку, передать управление bootloader с логотипом.
- **`D`**: Переключение интерактивного **Debug-оверлея**:
  - Текущий контекст C (функция, выполняемая стадия загрузки, строка исходника).
  - Дамп регистров процессора (`EAX`, `EBX`, `ECX`, `EDX`, `ESI`, `EDI`, `EBP`, `ESP`, `EIP`, `EFLAGS`).
  - Поток дизассемблированных инструкций x86 вокруг `EIP` с подсветкой выполняемой команды.
- **`H`**: Немедленный **Halt** системы (`cli; hlt`).

## Сборка и запуск

```bash
# Сборка образа диска build/ios_boot.img
make

# Запуск в QEMU
make run
```
